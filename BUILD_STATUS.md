# Nexus Admin Tools 1.8.2 — test candidate

Собран на локальных библиотеках Valheim, BepInEx и Jötunn, целевая платформа netstandard2.1. Сетевой протокол повышен до 181; версия 1.8.2 должна совпадать на сервере и каждом клиенте.

Включены общий поиск и предыдущая структура большого HUD, исправление Namekeeper для наборов, телепорт по всем рассчитанным уникальным точкам мира, включая зоны, которые ещё не загружал игрок, с возвратом, пользовательские точки телепорта, переименование Nexus и удаление пользовательских точек, погодный режим, остановка/отключение рейдов, общий журнал и бесконечная перезарядка силы босса.

Пользовательское имя изменено на Nexus Admin Tools. Сетевые операции с точками проверяются и выполняются сервером; точки и переименования хранятся по UID мира в конфигурации сервера.

Автоматическая проверка кода и пакетов описана в `TEST_RESULTS.json`; журнал аудита сетевой архитектуры — `NETWORK_AUDIT.md`. Живой игровой и сетевой тест этой версии ожидает ручного выполнения плана `TEST_PLAN_1.8.2_RU.md`.
