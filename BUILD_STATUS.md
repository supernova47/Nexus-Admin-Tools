# Nexus Admin Tools 1.8.7 — рабочая сборка

Сборка 1.8.7 зафиксирована пользователем как рабочая для выпуска 2026-10-19. DLL установлена на выделенный сервер, прежняя версия сохранена в резервной папке.

Сборка сделана для Valheim, BepInEx и Jötunn на netstandard2.1. Ошибок компиляции нет; остаются два предупреждения MSB3277 о конфликтах версий системных библиотек.

Протокол сетевых команд — 185, без изменений относительно 1.8.5. Сетевые действия выполняет сервер после проверки прав администратора. Закрытие точки возврата разрешено только игроку, которому эта точка принадлежит.

HUD и инвентарь работают независимо. Tab открывает инвентарь, пока HUD остаётся на экране; ввод для инвентаря и перетаскивания пропускается, игровые действия персонажа блокируются. Escape закрывает инвентарь первым нажатием, HUD — вторым. F6 и кнопка закрытия HUD сохранены. HUD получает верхний UI-слой, пока инвентарь открыт; значок предмета при перетаскивании получает следующий слой и не уходит под панель. Стак сразу сохраняется в корзину и удаляется из инвентаря при свежем серверном разрешении администратора; запись в журнал отправляется в фоне. Уведомление о точке возврата находится поверх окон, его кнопки доступны затронутому игроку без админских прав, а удаление точки фиксируется после ответа сервера. Очистка выброшенных предметов оставлена без изменений. Проверенная DLL 1.8.7 установлена в папку выделенного сервера, предыдущая 1.8.6 сохранена в `BepInEx/plugins/ValheimSpawner.backup-1.8.6`; сервер оставлен остановленным. Для проверки в игре импортируйте тот же Thunderstore ZIP в клиентский профиль и запустите сервер вручную.

Проверки прошли: 39 статических регрессий; 2 934 проверки правил протокола, ограничений и времени; 57 проверок очистки существ; 158 проверок IL сетевой авторизации, транспорта и HUD; 49 проверок API установленной игры; дымовые тесты избранного, сохранения наборов и имён Namekeeper. Thunderstore и исходный архив собраны и проходят проверку состава и контрольных сумм. README и changelog на английском, лицензия MIT.

Проверка UI и поведения инвентаря требует ручного запуска игры по `TEST_PLAN_1.8.7_RU.md`. Очистка выброшенных предметов в 1.8.5 была проверена пользователем; её код в этой версии не менялся.
