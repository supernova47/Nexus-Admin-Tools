# Nexus Admin Tools 1.8.2 — Admin Features

Вкладка «Мир»: номер дня и время Valheim, установка времени, погодный режим и управление набегами. Погода и переключатель набегов являются настройками мира на сервере, сохраняются после перезапуска и отправляются всем клиентам. Отключение набегов останавливает текущий рейд и блокирует новые до включения.

Вкладка «Локации»: страницы всех уникальных точек, рассчитанных генератором по всей карте, включая зоны, которые сервер или игрок ещё не загружал. Nexus проверяет выбранные координаты на сервере, запоминает точку администратора и возвращает его по кнопке. Администратор может сохранить текущую позицию как общую точку мира, переименовать игровые и пользовательские точки в Nexus, а пользовательские — удалить. Игровые имена в самом мире не меняются.

Вкладка «Журнал»: общий серверный журнал. Запись содержит UTC-время, день мира, имя и UID администратора, команду с параметрами и результат. Последние 1 000 записей доступны в окне; файл `BepInEx/config/SuperNova.ValheimNexus.AdminAudit.log` хранится на сервере, архив `.1` создаётся при ротации на 1 MiB.

Вкладка «Игрок»: бесконечная перезарядка силы боссов обнуляет только перезарядку администратора, пока включён переключатель. После применения одной силы можно переключиться на другую и применить её сразу; длительность действующего эффекта остаётся обычной.

Права проверяются сервером на каждом запросе по списку администраторов. Локальные включённые режимы сохраняются для мира и персонажа и вновь применяются только после подтверждения прав. Серверные погодные/рейдовые настройки привязаны к миру.
