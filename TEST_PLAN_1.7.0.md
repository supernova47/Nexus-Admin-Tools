# Nexus 1.7.0 — manual multiplayer acceptance

Status: not executed by Codex. Use a test world/character. Required participants: dedicated server, admin client A, ordinary client B; add admin client C for ownership migration. Use matching Nexus/Jötunn installations.

1. **Handshake:** matching 1.7.0 peers connect; a 1.6.0/missing-Nexus client is rejected by Jötunn compatibility checks. Server startup in headless mode creates no UI.
2. **Ordinary player:** B cannot open F6 HUD, use F7/F8, enable infinite resources/ghost/fly/no-cost/XP/damage through saved config, or invoke world/local grants. B can still see custom item names and A's authorized ghost state.
3. **Admin authentication:** A in server `adminlist.txt` receives the compact panel. Remove A from the list while connected: new actions are denied immediately on the server, continuous effects stop and the panel closes within 2.5 seconds of the last permission grant. Restore A and test reconnection.
4. **Connection loss:** lose the server connection while a local grant is pending. No grant is executed after timeout/disconnect or when connecting to another server; fly/no-cost/ghost return to prior state. A delayed or duplicate reply cannot execute a grant twice.
5. **Spawn:** A spawns one and several creatures, levels 1–3, named/tamed where supported, in front and at crosshair. B and C see exactly the requested count, name, stars, and tame state. A target over 30 m from A is rejected. A missing/nonnetworked/player prefab is rejected.
6. **Ownership:** B owns a nearby creature's simulation. A uses ordinary damage and super damage: only A's configured hit is multiplied once; damage by B is unchanged; players and tamed creatures are excluded. Repeat after the creature's owner changes.
7. **Ghost:** enable A's ghost while a hostile creature already targets A and B owns its AI. The creature drops A and may target visible B. Repeat with server-owned mobs, flying mobs, animals, a new mob, ownership transfer and newly joining C. Disable ghost, revoke A's rights, disconnect A: targets become eligible normally after snapshot refresh. PvP remains unchanged. Already fired attacks/environment hazards may still hurt A.
8. **Time:** all participants see the same day/time. Choose a future time today, a time already passed today, midnight, sunrise and sunset; the raw clock moves forward only, and day increments when necessary. Reconnect: the chosen field remains but time is not set again. Sleep/time skip rejects a competing change.
9. **Persistence:** toggle every admin option; set XP/damage, selected skill/target, hours/minutes, cleanup target flags and subcategory. Log out, restart the client and rejoin the same world/character: choices restore after authorization. Change character or world: independent defaults/settings. Restore rights after losing them: desired choices remain in config. Invalid saved flags/NaN/out-of-range multipliers are sanitized.
10. **Skills:** choose an untrained skill and raise to a specific level, then raise all to 100. The same button must be pressed twice within 8 s. B's skills are unchanged. Levels never decrease. Save/logout/reload: new levels persist with the character. XP multiplier changes training only, and does not distort direct level setting. Test modded registered skills if present.
11. **Inventory:** grants and kits require authorization for A; custom unstackable names/descriptions survive save/reload and display for B. Partial/full inventory does not duplicate or silently lose items. Repair/fill-stacks/heal affect A only. Changing a selected item/kit while waiting cannot change the approved action snapshot.
12. **Cleanup:** explicit confirmation, 5–100 m configured radius, 200-target cap. Players never die; boss/tame exclusions work by default and when changed. Revoke admin before confirm: server denies. Repeat with mobs owned by B.
13. **UI:** RU/EN, 1280×720, 1920×1080, 2560×1440 and ultrawide; game UI scale changes. Right panel fits inside the canvas. Search and input do not fire F7/F8; chat/console/text fields do not fire Z/B. Dropdowns, nested scroll areas, favorites, filter/paging, amount reset/remainder, tooltips and keyboard focus remain usable. F6/Escape restore cursor/input; death/scene unload closes the panel. Other mod UI input blocks survive closing Nexus.
14. **Workbench:** kits import/export/edit/deep copies, history filters/replay controls, diagnostics and radar snapshot comparison retain the existing data. Back returns to the native panel. The stable 1.6.0 Advanced Format 2 files and `.bak` migration are preserved.

Record game version, mod versions, server/client logs and observed results before promoting the package to stable.
